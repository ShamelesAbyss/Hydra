## Permanent boundaries

- Native Rust; preserve headless/Ratatui and native Hyperliquid engine.
- No multiple dashboard windows, detached heads, cloud dependency or replacement of
  actual functionality with a visual mockup.
- Graphical/research work remains independent of critical engine execution, risk,
  database persistence and signing. No real-money activation during development.
- Unknown/unresolved/blocked/faulted/unavailable states remain visible. Prepared
  action is not submitted, acknowledgment is not fill, and no execution success is
  animated without authoritative evidence. Simulated/live observations stay distinct.
- Idle breathing/atmosphere may be decorative; event energy must reflect real work.
- Preserve all historical releases, tests, safeguards, exact final README memorial,
  automated verification and distribution requirements. Work exclusively on main.

actual native code, inspect/capture screenshots, measure rendering, verify resizing
and selection, run tests/audit, update this ledger/major milestone matrix/docs,
commit/push main, publish verified executables/checksums, verify exact tagged CI.

implemented behavior and evidence. Unmet target-hardware/performance limits must
remain explicit; screenshots/concept art are not performance certification.
